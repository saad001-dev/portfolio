# Portfolio

Personal portfolio website showcasing web development projects, skills, and contact information.

## 🌐 Live Demo

[View Live Portfolio](https://your-vercel-link.vercel.app)

## ✨ Features

- Responsive modern UI with dark theme
- Smooth scroll animations (Framer Motion)
- Interactive hero section with typing animation
- Projects showcase with cards
- Skills & progress bars
- Work experience timeline
- Contact form (Gmail compose integration)
- Social links (WhatsApp, Facebook, Instagram, GitHub, LinkedIn)

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Fonts:** Custom (display + mono)
